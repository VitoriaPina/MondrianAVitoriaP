# Mondrian parte A 

Usei o illustrator para medir a imagem e conseguir que as posições ficassem o mais próximas possível da composição real. Para fazer as formas coloridas usei o rect, tendo feito contas antes para coincidirem corretamente no quadro total. Usei o fill para preencher com a cor certa. Finalmente, para fazer as linhas pretas defini um strokeWeight, e defini onde queria que as mesmas começassem e terminassem e comprimento das mesmas.
